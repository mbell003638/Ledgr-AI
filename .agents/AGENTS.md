
## Git Workflow Rule
- **NEVER** run git add, git commit, or git push automatically. Always wait for the user's explicit instruction to commit or push changes to git, even for minor bug fixes or follow-up corrections.
## Browser Automation Rule
- Do **not** use browser automation for GitHub, builds, deployments, or repository operations unless the user explicitly asks to use a browser. Prefer GitHub API or CLI authentication supplied by the user.
